# 🧠 Quiz Game

A simple, interactive Quiz Game developed using Python. This project allows users to answer multiple-choice questions, test their knowledge, and track their scores based on their answers.

## ✨ Features

* **Multiple-Choice Questions:** Answer questions by selecting an option.
* **Answer Validation:** Check whether the selected answer is correct.
* **Score Tracking:** Keep track of the user's score.
* **Instant Feedback:** Display whether an answer is correct or incorrect.
* **Final Score:** Display the total score at the end of the quiz.
* **Interactive Interface:** Navigate through questions using the terminal.

## 🛠️ Technologies Used

* Python 3
* VS Code

## 📚 Concepts Practiced

* Variables and Data Types
* Lists and Dictionaries
* Conditional Statements (if-else)
* Loops
* User Input and Output
* Comparison Operators
* Basic Problem Solving

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the Python file:

```bash
python quiz_game.py
```

4. Answer the questions displayed in the terminal.
5. Check your final score!

## 🎯 Project Objective

The objective of this project is to strengthen Python fundamentals through an interactive quiz application while practising conditional logic, data handling, and score management.
