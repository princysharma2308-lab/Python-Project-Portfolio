# 🏦 Banking System

A simple, menu-driven Banking System developed using Python. This project simulates basic banking operations and helps users understand how banking transactions work through a command-line interface.

## ✨ Features

* **Create Account:** Create a new bank account.
* **Check Balance:** View the current account balance.
* **Deposit Money:** Add money to the account.
* **Withdraw Money:** Withdraw money from the account.
* **Transaction Handling:** Perform basic banking operations.
* **User-Friendly Menu:** Navigate through different banking options.

## 🛠️ Technologies Used

* Python 3
* VS Code

## 📚 Concepts Practiced

* Variables and Data Types
* Conditional Statements (if-else)
* Loops
* Functions
* User Input and Output
* Basic Logical Thinking

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the Python file:

```bash
python banking_system.py
```

4. Follow the instructions displayed in the terminal.

## 🎯 Project Objective

The objective of this project is to strengthen Python programming fundamentals by building a practical banking application that demonstrates basic account management and financial transactions.
