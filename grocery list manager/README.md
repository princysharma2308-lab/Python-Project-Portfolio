# 🛒 Grocery List Manager

A simple, menu-driven Grocery List Manager developed using Python. This project helps users manage their grocery items by adding, viewing, searching, and removing items from a shopping list.

## ✨ Features

* **Add Items:** Add new grocery items to the list.
* **View List:** Display all grocery items.
* **Search Items:** Check whether a particular item exists.
* **Remove Items:** Delete items from the grocery list.
* **Interactive Menu:** Navigate through different options easily.

## 🛠️ Technologies Used

* Python 3
* VS Code

## 📚 Concepts Practiced

* Variables and Data Types
* Lists
* Conditional Statements (if-else)
* Loops
* User Input and Output
* List Methods
* Basic Problem Solving

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the Python file:

```bash
python grocery_list_manager.py
```

4. Follow the instructions displayed in the terminal.
