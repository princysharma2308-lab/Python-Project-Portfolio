# 📒 Contact Diary

A simple, menu-driven Contact Diary application developed using Python. This project allows users to manage their contacts by storing names and contact details, searching for existing contacts, updating information, and deleting contacts.

## ✨ Features

* **Add Contact:** Save a new contact with a name and phone number.
* **View Contacts:** Display all saved contacts.
* **Search Contact:** Find a contact using their name.
* **Update Contact:** Modify the details of an existing contact.
* **Delete Contact:** Remove a contact from the contact diary.
* **Interactive Menu:** Navigate through different contact management options.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the Python file:

```bash
python contact_diary.py
```

4. Follow the instructions displayed in the terminal.

## 🎯 Project Objective

The objective of this project is to strengthen Python programming fundamentals by developing a practical contact management application and understanding how data can be stored, accessed, updated, and deleted using dictionaries.
